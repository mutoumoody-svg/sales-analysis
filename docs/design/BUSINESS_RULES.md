如果：

标记：

Potential Wholesale

---

# 三、库存预测规则


零售销量：

用于日常库存预测。


批发销量：

独立分析。


禁止：

批发订单直接平均进入零售预测模型。


原因：

避免大型订单影响日常补货。


---

# 四、成本规则


## 核心原则


同一个 SKU

允许：

不同店铺

不同成本。


例如：


SKU A


天猫：

18元


京东：

19元


抖音：

20元

2.

Channel Cost

渠道成本


3.

SKU Standard Cost

标准成本


4.

默认成本

# 成本缺失规则


如果没有成本：

禁止：

使用0成本计算利润。


必须：

生成异常提醒。


状态：

Cost Missing
