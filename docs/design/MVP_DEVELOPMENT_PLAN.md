# MVP DEVELOPMENT PLAN

# AI 企业经营决策平台 MVP 开发计划 V0.1


## 1. MVP目标


第一阶段目标：

建立一个可以运行的企业经营分析系统。


重点验证：

1. 数据是否可以正确进入系统

2. 利润计算是否准确

3. 不同店铺不同成本是否可以处理

4. AI是否可以生成经营建议
